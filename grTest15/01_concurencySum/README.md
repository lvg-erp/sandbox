Задача 1: Конкурентное суммирование чисел
Описание: Есть массив чисел. 
Нужно запустить несколько горутин, 
каждая из которых считает сумму своей части массива, 
и потом объединить результаты.

numbers := []int{1, 2, 3, 4, 5, 6, 7, 8}
Задача: Разделить массив на части, обработать их в горутинах и получить итоговую сумму.
