Обработка данных из нескольких источников

Описание: Реализуйте систему, которая читает данные из нескольких источников 
(например, из каналов, симулирующих датчики). 
Каждому источнику присвойте свою горутину, которая генерирует данные каждые несколько миллисекунд. 
Основной поток должен собирать данные из всех источников и выводить их. 
Используйте контекст для остановки всех горутин через определённое условие (например, через тайм-аут).

Требования:

Создайте 3-5 канальных источника, которые генерируют случайные данные и передают их на главный канал.
Используйте context.Context для отмены всех горутин через тайм-аут (например, через 5 секунд).
Горутины источников должны завершаться при отмене контекста.
В основном потоке выводите пришедшие данные.
