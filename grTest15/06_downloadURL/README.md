Параллельное скачивание файлов

Описание: Напишите программу, которая параллельно скачивает 
содержимое нескольких URL-адресов и выводит их размер и статус. 
Используйте горутины для одновременного скачивания, каналы для передачи результатов, 
а контекст — для отмены всех задач по сигналу пользователя или по тайм-ауту.

Требования:

Создайте список URL-ов (можно статический).
Для каждого URL запустите отдельную горутину для скачивания.
Передавайте результаты (успех/ошибка, размер файла) через канал.
Если пользователь прерывает программу (например, по нажатию Ctrl+C), 
отмените все активные задачи с помощью контекста.
Выведите итоговую информацию о каждом файле по завершении.
