Написать программу на Go, которая:

принимает массив из 1000 случайных целых чисел (диапазон от -500 до 500)
параллельно (с помощью горутин) для каждого числа вычисляет:
квадрат числа
факториал модуля числа (если |x| ≤ 12, иначе просто 0)
является ли число простым (true/false)

результаты по каждому числу сохранять в отдельный результирующий срез структур
использовать каналы для передачи чисел в горутины и получения результатов обратно
использовать sync.Mutex для безопасного добавления результатов в общий слайс
количество воркеров (горутин) задаётся константой (например 8)
