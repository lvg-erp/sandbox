Создайте программу, которая:

Имеет общий счетчик (тип int), доступный из нескольких горутин.
В программе запускается N горутин, каждая из которых увеличивает счетчик M раз.
Ограничьте одновременно запущенные горутины по L (например, используя канал как семафор).
Все операции защищены мьютексом (для потокобезопасности).
Используйте Go generics для обобщения типа столбца (например, любой числовой тип).
