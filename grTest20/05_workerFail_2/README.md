Условие
Тебе нужно написать программу, которая:

Создает 3 воркера для вычислений

Каждый воркер читает числа из своего канала и возводит их в квадрат

Диспетчер распределяет задачи между воркерами по кругу (round-robin)

Если воркер падает (например, при получении числа 5) - он должен перезапуститься

Все результаты собираются в один выходной канал

Входные данные
Числа от 1 до 10 отправляются в систему

Задержка между отправками: 100ms

Выходные данные
Квадраты чисел (кроме числа 5, которое вызывает панику)

Программа должна обработать все числа, кроме 5
