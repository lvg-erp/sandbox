Описание: Реализовать систему обработки задач с приоритетами, где задачи поступают из слайса и обрабатываются воркерами, 
реализующими интерфейс PrioritizedWorker. Статистика обработанных задач хранится в мапе, а тикер периодически выводит 
текущую статистику. Контекст управляет завершением обработки. 
Задачи имеют приоритет (высокий или низкий), и воркеры обрабатывают их с учетом приоритета.

Условие

Интерфейс PrioritizedWorker:

Методы:
gotype PrioritizedWorker interface {
Process(task Task) (int, error) // Обрабатывает задачу, возвращает результат и ошибку
GetID() string                  // Возвращает ID воркера
}

Task — структура:
gotype Task struct {
ID       int
Priority int // 1 для высокого приоритета, 2 для низкого
Value    int // Значение для обработки
}



Структура TaskStats:

Поля:

stats map[string]int: Количество задач, обработанных каждым воркером (ключ — ID воркера).
mu sync.Mutex: Для потокобезопасности.
stop chan struct{}: Для завершения мониторинга.


Методы:

Record(workerID string): Увеличивает счетчик задач для воркера.
Snapshot() map[string]int: Возвращает копию мапы статистики.
Stop(): Останавливает фоновую горутину мониторинга.




Функция ProcessTasks:

Сигнатура: ProcessTasks(ctx context.Context, tasks []Task, workers []PrioritizedWorker) ([]int, error).
Принимает контекст, слайс задач и слайс воркеров.
Распределяет задачи между воркерами с учетом приоритета (высокоприоритетные задачи обрабатываются первыми).
Использует TaskStats для отслеживания статистики.
Периодически (каждые 3 секунды) выводит статистику через тикер.
Возвращает слайс результатов обработки задач и ошибку (если контекст отменен).


Требования:

Высокоприоритетные задачи (Priority == 1) обрабатываются раньше низкоприоритетных (Priority == 2).
Воркеры обрабатывают задачи параллельно через каналы.
Статистика потокобезопасна (использовать мьютекс).
Контекст управляет завершением воркеров и мониторинга.
Проверить код с -race.



Пример поведения

Вход:
gotasks := []Task{
{ID: 1, Priority: 1, Value: 2},
{ID: 2, Priority: 2, Value: 3},
{ID: 3, Priority: 1, Value: 4},
{ID: 4, Priority: 2, Value: 5},
}

Два воркера (worker1, worker2), каждый удваивает Value.
Вывод статистики каждые 3 секунды, например: {"worker1": 2, "worker2": 2}.
Результат: [4, 6, 8, 10] (высокоприоритетные задачи [2, 4] обработаны первыми).
При отмене контекста: частичные результаты и ошибка ctx.Err().
