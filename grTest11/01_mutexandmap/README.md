Мьютексы + Мапы:
Реализовать потокобезопасную структуру Cache с мапой map[string]interface{} 
для хранения ключей и значений произвольного типа. Методы:

Set(key string, value interface{}, ttl time.Duration): 
добавляет ключ-значение с временем жизни (TTL). После истечения TTL ключ автоматически удаляется.
Get(key string) (interface{}, bool): возвращает значение и флаг существования ключа.
Delete(key string): удаляет ключ.
Использовать мьютекс для синхронизации и горутину для очистки устаревших ключей по истечении TTL. 
Обеспечить потокобезопасность и отсутствие гонок данных.
