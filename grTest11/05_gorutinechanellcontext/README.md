Реализовать функцию Pipeline(ctx context.Context, input []int) ([]int, error), 
которая создает трехэтапный конвейер обработки чисел из входного слайса input. 
Каждый этап выполняется в отдельной горутине, обмениваясь данными через каналы. 
Конвейер состоит из следующих этапов:

Фильтрация: Оставляет только четные числа.
Удвоение: Удваивает отфильтрованные числа.
Суммирование: Суммирует числа в пределах каждого 5-секундного окна.
Функция должна использовать контекст для отмены обработки (например, по таймауту или явной отмене) 
и возвращать итоговые суммы или ошибку при отмене/таймауте.
