Реализовать функцию RateLimitedWorker(jobs <-chan int, results chan<- int, rate time.Duration), которая:

Читает числа из входного канала jobs.
Выполняет вычисление над каждым числом (например, возведение в квадрат).
Ограничивает скорость обработки так, чтобы вычисления выполнялись не чаще, 
чем раз в заданный интервал rate (например, раз в 500 мс).
Отправляет результаты вычислений в выходной канал results.
Закрывает канал results после обработки всех задач.
Корректно завершает работу, когда входной канал jobs закрывается.
Использует time.Ticker для реализации ограничения скорости.
