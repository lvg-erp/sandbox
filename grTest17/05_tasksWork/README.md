Подробное описание задачи: "Обработка задач с тайм-аутом и отменой"
Цель:
  Создать программу, которая запускает несколько задач параллельно, управляет их выполнением с помощью контекста и каналов, 
  и корректно обрабатывает ситуации, когда задачи завершаются успешно или прерываются по тайм-ауту.

Требования и шаги:
  Количество задач:
  Общее число задач задайте, например, 5. Можно сделать параметром.

Каждая задача:

Запускается в отдельной горутине.
    Имеет уникальный ID (например, число от 1 до N).
    Имитацией долгой операции (например, time.Sleep) означает, что она занимает некоторое случайное время (например, от 1 до 5 секунд).
    При завершении операции, отправляет результат или сообщение о статусе (успех/тайм-аут) в канал.
    Контекст с тайм-аутом:

Каждая задача должна иметь свой собственный контекст (context.WithTimeout), с тайм-аутом 2 секунды.
    Если задача не завершилась за время, она должна отмениться (не продолжать работу), и в канал следует отправить сообщение о тайм-ауте.
Коммуникация через канал:

Используйте канал для отправки результатов выполнения задач.
    Каждая отправляемая структура должна содержать:
        ID задачи.
        Статус (успех, тайм-аут, отмена).
        Время выполнения (опционально).
Главная функция:

    Запускает все задачи.
    Следит за каналами и выводит результат по каждой задаче.
    После получения всех результатов или при явном завершении, программа должна завершиться корректно.
Обработка ошибок и завершение:

После получения всех результатов, программа должна завершиться.
    Обеспечьте правильную синхронизацию (например, с помощью sync.WaitGroup), чтобы не было гонки при завершении.
Рекомендации:
    Используйте context.WithTimeout для ограничения времени выполнения каждой задачи.
    Реализуйте функции, которые читают результат или тайм-аут и выводят сообщения.
    Для имитации случаев тайм-аута, задавайте случайную задержку больше 2 секунд для части задач.
