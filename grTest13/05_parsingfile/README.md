Напишите программу, которая рекурсивно обходит директорию (как в задаче 1) 
и подсчитывает частоту слов во всех текстовых файлах (.txt). 
Используйте горутины для параллельного чтения файлов, контекст для ограничения времени (10 секунд) 
и тикер для вывода промежуточной статистики каждые 2 секунды.

Требования:

Рекурсивно обойти директорию, фильтруя файлы .txt.
Подсчитать частоту слов (например, map[string]int).
Использовать горутины для чтения файлов.
Ограничить время выполнения контекстом (10 секунд).
Выводить статистику (число обработанных файлов и общее количество слов) каждые 2 секунды.
Сохранить результат в JSON.

Подход:

Используйте os.ReadDir для рекурсивного обхода.
Запускайте горутину для каждого .txt файла, считывая слова с bufio.Scanner.
Используйте sync.Mutex или канал для безопасного обновления map[string]int.
Примените context.WithTimeout и time.NewTicker.
