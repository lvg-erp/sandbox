Задача 1: Конкурентный поиск максимального элемента
Описание: Реализовать функцию FindMaxConcurrently, которая находит максимальный элемент в слайсе целых чисел, 
используя несколько горутин для параллельной обработки. 
Статистика обработанных элементов воркерами хранится в мапе, 
а тикер периодически выводит текущую статистику. Контекст управляет завершением.


Требования:

Интерфейс MaxFinder:
gotype MaxFinder interface {
FindMax(slice []int) (int, error)
GetID() string
}

FindMax: Находит максимум в подмножестве слайса.
GetID: Возвращает ID воркера.


Структура StatsTracker:

Хранит мапу map[string]int (ID воркера → количество обработанных элементов).
Методы: Record(workerID string), Snapshot() map[string]int, Stop().
Фоновая горутина с тикером (2 секунды) выводит статистику.


Функция FindMaxConcurrently:

Сигнатура: FindMaxConcurrently(ctx context.Context, numbers []int, workers []MaxFinder) (int, error).
Делит слайс numbers на части, распределяет между воркерами через канал.
Каждый воркер находит максимум в своей части, используя FindMax.
Собирает результаты и возвращает глобальный максимум.
Использует StatsTracker для отслеживания обработанных элементов.
Уважает ctx.Done() для завершения.


Условия:

Потокобезопасность для статистики и результатов.
Проверка с -race.
Обработка случаев: пустой слайс, отсутствие воркеров.



Пример:

Вход: numbers = [3, 1, 4, 1, 5, 9, 2, 6], два воркера.
Вывод статистики: {"worker1": 4, "worker2": 4} (каждый обработал половину слайса).
Результат: 9 (максимум).
