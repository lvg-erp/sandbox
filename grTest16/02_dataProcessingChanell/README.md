Асинхронная обработка данных с использованием каналов и указателей
Описание:
Есть массив чисел. Необходимо запустить несколько горутин, 
каждая из которых возьмет элемент массива (по указателю), выполнит вычисление (например, возведение в квадрат), 
и отправит результат в канал. После завершения всех горутин, главная горутина должна собрать все результаты.

Требования:

Передавайте указатели на элементы массива.
Используйте WaitGroup для ожидания завершения.
Передавайте результаты через канал.
