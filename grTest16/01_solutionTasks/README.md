Создайте пул из N работников (горутин), которые обрабатывают входящие задания из очереди (канала). 
При получении сигнала отмены через context, все горутины должны завершиться.

Требования:

Используйте context для отмены работы.
Передавайте указатели туда, где необходимо.
Обеспечьте корректное закрытие каналов и завершение всех горутин.
/////********************************************************************///////////////////////////////////////////
Чтобы обеспечить мгновенную реакцию на отмену, нужно использовать select внутри самой задачи, и запускать time.After() 
как отдельную операцию, а не сразу в select. Вот как:

go

select {
case <-ctx.Done():
fmt.Printf("Task canceled %d\n", t.id)
return
case <-time.After(t.duration):
// задача завершена успешно
}
Но, чтобы прервать time.After(), его нужно заменить на time.NewTimer, который можно остановить:

go

timer := time.NewTimer(t.duration)
defer timer.Stop()

select {
case <-ctx.Done():
fmt.Printf("Task canceled %d\n", t.id)
return
case <-timer.C:
storeChan <- t.id
}
Если ctx.Done() сработает раньше, то timer.Stop() поможет отменить таймер, и задача завершится мгновенно без лишнего ожидания.
