Конкурентный подсчет суммы элементов массива с каналами и указателями
Описание:
Дано большое число элементов. Необходимо разбить их на части, 
запустить горутины для подсчета суммы каждой части (по указателю на массив или части). 
Затем собрать итоговую сумму.

Требования:

Используйте указатели для доступа к разделам массива.
Передавайте результаты через каналы.
Гарантировать корректность подсчета.
