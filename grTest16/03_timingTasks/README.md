Таймер с отменой выполнения задачи
Описание:
Создайте функцию, которая выполняет долгую операцию (например, time.Sleep) 
в горутине и использует context с тайм-аутом. 
Если не завершилась операция за отведенное время, отмените задачу.

Требования:

Передавайте указатель context в функцию.
Испольуйте select для обработки context.Done().
