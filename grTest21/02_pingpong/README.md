Создай систему, в которой:

Есть канал ping и канал pong.

Запускается 3 воркера, которые читают из канала ping и пишут в канал pong (преобразуют строку в верхний регистр).

Запускается 2 воркера, которые читают из pong и пишут в ping (преобразуют строку в нижний регистр).

Главная горутина отправляет начальное сообщение "Hello" в ping.

Каждые 2 секунды должен срабатывать таймер, который выводит в лог текущее состояние: сколько сообщений прошло через систему.

Программа работает 20 секунд, затем завершается (используй time.After для завершения).
